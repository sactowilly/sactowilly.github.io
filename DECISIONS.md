# Decisions

## Preserve the static GitHub Pages architecture

**DECISION:** Keep the site dependency-free with one HTML document, one stylesheet, and one small JavaScript file.
**RATIONALE:** The existing repository already publishes reliably from GitHub Pages, and the redesign does not need a framework or build step.
**DATE:** 2026-08-03
**PARTIES:** Will Zrnchik and Codex

## Make the privacy boundary visible and structural

**DECISION:** Feature only a curated set of public GitHub repositories and exclude employer-specific names, systems, customers, pricing, and proprietary material from content and metadata.
**RATIONALE:** The portfolio must demonstrate capability without exposing confidential business context.
**DATE:** 2026-08-03
**PARTIES:** Will Zrnchik and Codex

## Use the Digital Foundry visual system

**DECISION:** Use black, charcoal, white, and orange with Inter-style sans-serif typography, editorial serif accents, and industrial grid details.
**RATIONALE:** The system supports the requested brand while keeping the site professional, distinctive, and readable.
**DATE:** 2026-08-03
**PARTIES:** Will Zrnchik and Codex
