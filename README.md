# sactowilly — Digital Foundry

The source for [sactowilly.github.io](https://sactowilly.github.io/), Will Zrnchik's public portfolio for practical AI systems, workflows, and experiments.

## Brand direction

- Black, charcoal, white, and foundry orange
- Direct, editorial typography with Inter-style system fallbacks
- Practical systems language rather than generic AI imagery or hype
- Responsive, accessible, dependency-free static HTML, CSS, and JavaScript

## Public portfolio boundary

This repository and website may include only:

- Public GitHub repositories selected for the portfolio
- General professional background and capabilities
- Public brand assets approved for the site

They must not include employer systems, customer or prospect information, customer lists, internal pricing or financial data, proprietary processes, private screenshots, secrets, or confidential business material.

## Local preview

Serve the repository root with any static web server, then open `index.html` through that server. GitHub Pages publishes the `master` branch from the repository root.

## Files

- `index.html` — content, metadata, and structured data
- `styles.css` — responsive visual system
- `script.js` — navigation, header, and reveal behavior
- `assets/` — public image assets
- `robots.txt` and `sitemap.xml` — crawler support

## Deployment

Changes pushed to the configured GitHub Pages source are published at [sactowilly.github.io](https://sactowilly.github.io/).
